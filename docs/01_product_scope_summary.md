# 01 Product Scope Summary

## 1. 产品定位

V1 是一个面向丧宠用户的 iOS App + H5 访客页产品。核心定位是：为离开的宠物留下一颗温柔、克制、可反复回看的线上纪念星球。

产品不是宠物社区、相册工具、AI 复活服务、殡葬服务、心理治疗工具或游戏养成系统。V1 的重点是先跑通创建、纪念、分享、抱抱、主人回访的基础闭环。

## 2. 核心用户

| 用户类型 | 说明 | V1需求 |
| --- | --- | --- |
| 宠物主人 | 刚经历或已经经历宠物离世的人 | 创建纪念空间、保存照片和故事、回来看看TA、接收熟人抱抱 |
| H5访客 | 主人主动分享链接后访问的人 | 无需登录查看纪念页，轻轻抱抱TA |

访客不是泛社交用户，V1 不做访客主页、评论、留言、共同编辑、关注或推荐。

## 3. 核心闭环

```text
主人创建宠物星球
→ 主人在App首页看到TA
→ 主人进入回忆页补充故事和照片
→ 主人分享H5纪念页
→ 访客打开H5
→ 访客点击抱抱
→ 主人在App内看到抱抱记录
→ 主人再次回到产品
```

该闭环必须在免费档中完整跑通。付费档只增强容量、信箱和保存感，不阻断基础闭环。

## 4. App端范围

V1 App 端负责主人侧能力：

- 未入驻首页；
- 登录 / 账号绑定；
- 宠物最小创建流程；
- 主照片上传；
- 权益选择；
- 首页星球观察窗；
- 回忆Tab下的宠物纪念主页；
- 纪念语；
- TA的故事；
- 相册照片；
- 天堂信箱；
- 抱抱记录；
- 分享面板；
- 权限设置；
- 我的Tab；
- 权益与升级；
- 购买记录 / 恢复购买；
- 宠物资料编辑；
- 客服、协议、隐私、注销等基础支撑入口。

## 5. H5端范围

V1 H5 端只承接主人分享：

- H5宠物纪念页；
- 访客无需登录查看；
- 访客抱抱；
- 抱抱成功状态；
- 已抱抱状态；
- 私密 / 不可访问状态；
- 弱 App 打开 / 下载 / 创建 CTA。

H5 不做强制登录、强制下载、评论、留言、打赏、访客上传、共同编辑、推荐其他宠物。

## 7. V1明确不做

V1 不新增以下功能：

- 社区、发现页、寻觅页、公共星球地图；
- 消息中心、系统Push、周年提醒；
- 评论、留言、访客上传、共同编辑；
- 关注、粉丝、推荐、排行榜、热度、访问量榜单；
- AI聊天、宠物回复、宠物复活、AI动态宠物；
- 游戏养成、任务系统、积分、打卡、奖励；
- 商城、电商促销、倒计时营销；
- 复杂多宠管理；
- 视频上传；
- 公开搜索和公开故事流。

## 8. HTML原型中的产品体验层

以下内容可作为正式产品体验参考：

- App 首页 / 回忆 / 我的底部Tab结构；
- 未入驻到创建完成的主流程；
- 首页星球观察窗；
- 回忆页模块顺序；
- 故事、相册、天堂信箱、抱抱记录的页面职责；
- H5访客页与App端的边界；
- 免费 / 付费权益边界；
- 权限状态：仅自己可见、链接可见、抱抱开关；
- 空状态、失败状态、不可访问状态的文案方向；
- H5抱抱闭环。

## 9. HTML原型中的开发走查层

以下内容只服务开发理解，不应进入正式产品：

- 右侧“开发走查面板”；
- 状态切换器；
- 快速跳转；
- 当前 state 展示；
- 页面路由说明；
- PRD 页面映射；
- 开发测试能力按钮；
- mock 数据对象说明；
- 模拟上传、模拟支付、模拟H5状态入口；
- “开发导航”；
