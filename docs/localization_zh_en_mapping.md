# Localization: zh / en Mapping

App Chinese name: **留光**  
App English name: **Pawlight**

Translation tone: gentle, restrained, private, memorial. Key conventions:
- 天堂信箱 → "Letters to Them"
- TA的故事 → "Their Story"
- 抱抱 → "hug" / "Send a gentle hug"
- 星球 → "little planet"（世界观锚点）
- 纪念空间 → "Memorial Space"（功能/设置语境）
- 完整纪念空间 → "Full Memorial Space"（情绪/描述语境）；方案选择卡片内保留 "Full Plan"
- 回忆 / Tab → "Memories"
- 注销账号 → "Sign out"（不是 Delete account）
- 通过链接可见 → "Visible by link"（不使用 link-visible）

## Implementation Notes

- **Language default**: English (`.en`)
- **Persistence**: `UserDefaults` key `app_language`, values `"en"` / `"zh"`
- **Toggle location**: 支持 section in Mine tab (Me → Support → Language)
- **iOS strings**: `ios/MemorialApp/Sources/Common/Utils/Strings.swift`
- **iOS language store**: `ios/MemorialApp/Sources/Common/Services/LanguageStore.swift`
- **H5 lang param**: iOS `SharePanelView` appends `?lang=en` or `?lang=zh`; H5 `page.tsx` reads `searchParams.lang`，默认 `"en"`
- **App display name**: `CFBundleDisplayName` = `Pawlight`（`Info.plist`）
- **App Chinese name**: 留光

### Full Plan vs Full Memorial Space 使用边界
- **方案选择卡片（TierSelectView）**：`Free Plan` / `Full Plan` ✓
- **情绪/成功/描述语境**：`Full Memorial Space` ✓
- **购买按钮**：`Unlock Full Memorial Space` ✓
- **禁止**：Full Planet、Pet Planet Plan、Planet Plan

### little planet 使用边界
- **世界观锚点**（onboarding title、success title、unboarded state、home planet window）：`little planet` ✓
- **功能/权益/设置语境**：`Memorial Space` / `keepsake` / `memories` ✓
- **禁止**：Pet Planet 作为功能名、把所有纪念空间都翻成 planet
