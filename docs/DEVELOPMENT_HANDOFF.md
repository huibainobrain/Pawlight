# DEVELOPMENT_HANDOFF

## 1. 项目一句话定位

为离开的宠物留下一颗温柔、克制、可反复回看的线上纪念星球；主人可以回来看看TA、补充回忆，也可以把H5纪念页分享给熟悉TA的人，让访客轻轻抱抱TA。

## 2. V1产品边界

V1只做 iOS App 主人端 + H5访客页。核心是创建、纪念、分享、抱抱、主人回访闭环。

V1不做社区、发现、消息、评论、访客留言、AI聊天、宠物回复、宠物复活、任务、积分、排行榜、商城、复杂多宠、系统Push、周年提醒、视频上传、AI动态宠物。

## 3. 核心闭环

```text
主人创建宠物星球
→ 首页看到TA
→ 回忆页补充故事和照片
→ 分享H5纪念页
→ 访客打开H5
→ 访客抱抱TA
→ 主人在App看到抱抱记录
→ 主人再次回到产品
```

免费档必须完整跑通该闭环。付费档只增强照片容量和天堂信箱。

## 12. 开发前仍需确认

进入真实开发前需确认：

- 主照片是否计入照片额度；
- 付费“更长期保存感”的法律/产品表达；
- H5分享链接是否长期有效；
- 访客抱抱去重方式；
- 是否需要删除照片；
- 是否需要删除宠物；
- 注销账号后的数据处理；
- H5 SEO和隐私边界；
- iOS支付路径和中国大陆支付规则；
- 图片存储成本；
- 敏感内容风控；
- 未来多宠、提醒和Push扩展口径。

未定义问题不要自行扩展，统一列入待确认。

## 14. 后续开发建议顺序

1. 评审 `03_data_model.md` 和 `04_api_spec.md`。
2. 锁定P0数据表和接口。
3. 先开发账号、单宠创建、主照片上传。
4. 开发首页和回忆主页。
5. 开发分享/H5访问权限。
6. 开发抱抱和抱抱记录。
7. 接入免费/付费权益判断。
8. 再做相册、故事、信箱、支付与我的Tab完整设置。
